super fast, minimal, and slopped alt tab alternative for mac

This project is not actively maintained. It's intended to meet exactly my needs.

## Install with Homebrew

On macOS 26 or later, run:

```sh
brew tap glasss13/alttab2 https://github.com/glasss13/alttab2.git
brew trust --cask glasss13/alttab2/alttab2
brew install --cask glasss13/alttab2/alttab2
```

Quit the original AltTab before opening AltTab2. Open AltTab2 and follow its setup prompts. Release builds are ad-hoc signed and may require first-launch approval in System Settings → Privacy & Security.
